# Phase 5.1 Animation Proof Asset

## Status

`core-sprout-review.png` is an AI-assisted, owner-review-required direction
sheet for the Phase 5.1 runtime proof. It is not published game content.

The sheet uses a 4x2 chroma-key grid:

1. calm idle;
2. curious idle;
3. left-foot waddle;
4. right-foot waddle;
5. attack anticipation;
6. short headbutt;
7. hit reaction;
8. recovered idle.

## Runtime Boundary

The proof scene uses locally preprocessed alpha spritesheets derived from the
review sheets. This demonstrates animation timing and lifecycle without
representing the source as a production atlas.

Production use still requires:

- human visual approval;
- cleaned alpha and edge validation;
- stable frame bounds and bottom-center pivot;
- optimized mobile-safe atlas and metadata;
- immutable asset publication;
- measured desktop and mobile performance.

AI generation does not grant publication approval.

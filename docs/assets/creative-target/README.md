# Creative Target Asset Notes

## Status

Every image in this directory is an AI-assisted documentation reference created
for the TitanCore Integrated Creative Target Pack on 2026-07-28.

These images are:

- not runtime or production assets;
- not approved for direct publication to players;
- not proof of copyright, licensing, accessibility, or technical validation;
- not a source of gameplay rules, room capacity, economy values, or live data;
- not allowed to bypass the human-review and asset-delivery pipeline.

Human artists or reviewers must establish final model sheets, turnarounds,
animation pivots, crops, UI states, localization, licensing, and optimized
runtime variants.

## Non-Authoritative Visual Labels

Generated labels, currencies, counts, equipment, and icons are illustrative.
In particular, `Party 4/4` does not replace the approved first-room target of
eight players. Final player counts and availability come only from the
authoritative room contract.

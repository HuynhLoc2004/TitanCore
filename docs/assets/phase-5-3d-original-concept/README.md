# Phase 5 Original 3D Concept Draft

`zephyr-frontier-concept-v1.png` is an AI-assisted, owner-directed concept draft
created specifically for TitanCore. It defines a candidate visual target for:

- the first original Core Raider silhouette;
- the Zephyr Frontier world identity;
- third-person camera scale and world framing;
- cloth, hair, weapon, crystal, foliage, atmosphere, and material direction;
- front/back modeling reference and facial-expression range.

This image is not a runtime asset, production model, final character approval,
loading screen, marketing image, or authorization to hardcode content.

No third-party character, game asset, logo, location, or interface may be copied
when translating this draft into production work. Production requires original
modeling, topology, UVs, materials, rigging, animation, LODs, collision,
optimization, human review, and publication through the approved asset pipeline.

The current primitive Three.js scene does not meet this concept's visual bar and
must remain a renderer/camera proof until replaced by reviewed original assets.
